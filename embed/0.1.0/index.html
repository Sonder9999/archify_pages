两块正文，完成接入

第一块 script src 引入库，库自动加载 CSS 和字体。第二块 script type="application/json" data-archify 保存原始图表，data-options 就是参数对象。同篇文章的后续图表只需再放 JSON 块；粘贴时保留 HTML 标签，去掉展示代码用的反引号围栏。

跟随博客主题

theme: "auto" 跟随宿主明暗；colorTheme: "hotaru" 读取 Hotaru 现有变量。其他博客可以传 colors，值支持 CSS 颜色和 var(--你的变量)。正文平台需要允许原始 HTML 与脚本；过滤脚本的平台无法仅靠正文接入。
